# «فلسطين: حكاية أرض وذاكرة»
### حزمة إنتاج فيلم وثائقي سينمائي قصير (~3 دقائق)

من فجر قرية فلسطينية إلى غروب على شاطئ غزة: الأرض، والبيت، والمفتاح، وشجرة الزيتون. حكاية مكانٍ صارت ذاكرةَ شعب، وما زالت تنتقل من جيل إلى جيل.

| | |
|---|---|
| المدة | 3:10 — ‏18 مشهدًا — 6 فصول |
| اللغة | العربية الفصحى + ترجمة إنجليزية |
| الصيغة | 16:9 — 4K — 24fps |
| اللقطات | 28 لقطة مولّدة بالذكاء الاصطناعي (تمثيلية) + أرشيف حقيقي + Motion Graphics |

## مسار الإنتاج المختصر
1. **البحث والتحقق:** راجع `08_SOURCES.md`، واحصل على الصور الأرشيفية وحقوقها (المشهدان 4 و6).
2. **تسجيل التعليق الصوتي** (`02_VOICEOVER.md`) وبناء Radio edit بطول ~3:10.
3. **الشخصيات أولًا:** ولّد Character sheets للشخصيات السبع واعتمد المراجع (دليل الشخصيات في `01_BLUEPRINT.md`).
4. **توليد الصور** (`03_IMAGE_PROMPTS.md`) بأداة واحدة ← **تحريكها** (`04_VIDEO_PROMPTS.md`) بأداة واحدة.
5. **اللقطات الحقيقية:** للمدينة وغزة (المشاهد 12–14) يُفضَّل ترخيص لقطات من مصوّرين فلسطينيين.
6. **Motion Graphics** (`05_MOTION_GRAPHICS.md`) — الخريطة من بيانات موثّقة فقط.
7. **الموسيقى والمؤثرات** (`06_MUSIC_AND_SFX.md`).
8. **المونتاج والتلوين والميكس والتسليم** (`07_EDIT_GUIDE.md`).

## المبادئ
- **التاريخ = أرشيف حقيقي.** لا صور تاريخية مولّدة، ولا تحريك بالذكاء الاصطناعي لصور أشخاص حقيقيين.
- **المولَّد = تمثيلي ومُعلَن** في الفيلم وفي وصفه.
- **لا رقم بلا مصدر.**
- **الكرامة أولًا:** لا دماء، لا مشاهد صادمة، لا صور نمطية، لا تأطير شفقة.
